# SecureWipe

## Problem Statement

Secure Data Wiping for Trustworthy IT Asset Recycling

## Objective

To develop a software platform that securely wipes data from IT
assets before recycling or reuse and provides verifiable proof
that the data wiping process has been completed successfully.

## Target Users

1. Organizations
2. IT Administrators
3. Recycling Centers
4. IT Asset Managers

## Core Features

1. User Authentication
2. IT Asset Registration
3. Asset Management
4. Wipe Policy Selection
5. Secure Data Wiping
6. Wipe Verification
7. Digital Certificate Generation
8. QR Code Based Certificate Verification
9. Audit Logs
10. Admin Dashboard
11. Reports and Analytics

## Advanced Features

1. AI-Based Wipe Policy Recommendation
2. Cloud Deployment
3. Role-Based Access Control
4. Automated Verification
5. API Integration

## Expected Workflow

Register Asset
       ↓
Select Wipe Policy
       ↓
Start Data Wiping
       ↓
Verify Wiping
       ↓
Generate Certificate
       ↓
Generate QR Code
       ↓
Verify Certificate

## Technologies

Frontend: React
Backend: Python FastAPI
Database: PostgreSQL
Authentication: JWT
Version Control: Git/GitHub
